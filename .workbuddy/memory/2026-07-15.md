- 实现（沿用 ntfy/gotify 的 self-hosted 简单 HTTP JSON 模式）：

  - `src/notification.py`：`NotificationChannel.BARK="bark"`、get_channel_name、NotificationService MRO+__init__、detect_configured_channels、_send_to_static_channel 分支。
  - `src/config.py`：新增 `bark_url/bark_device_key/bark_sound/bark_level/bark_group` 字段 + env 加载 + has_notification + 校验告警。
  - `src/notification_routing.py`：`ROUTABLE_NOTIFICATION_CHANNELS` 加 `"bark"`（支持 NOTIFICATION_*_CHANNELS=bark）。
  - `src/services/notification_diagnostics.py`：加 BARK spec；`src/notification_capabilities.py`：加 bark ChannelProfile(plain_text)。
  - `src/core/pipeline.py`：BARK 排除出 Markdown 转图片集合（与 ntfy/gotify 一致）。
  - `.env.example`：新增 Bark 配置段 + allowlist 加 bark；`docs/CHANGELOG.md`：[Unreleased] 加新功能条目。
- 验证：py_compile 全部通过；冒烟测试确认 endpoint 解析（公网/LAN/带/push 尾部/非法）、Bark 进入 routable、capabilities/diagnostics spec 存在、detect_configured_channels 在仅配 BARK_URL+BARK_DEVICE_KEY 时返回 ['bark']。
